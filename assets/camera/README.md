# 相机资产

把相机相关材料放进本目录，用于"相机进仿真场景"这一步（详见
[docs/08-roadmap.md](../../docs/08-roadmap.md) 阶段 2）。

**当前已放入**：`arm_mount_bracket_v3.step`（SO-ARM101 臂载支架 V3，Pro/E 导出的 STEP，
已用 `step_to_stl.py` 转换为 `mesh/arm_mount_bracket_v3.stl`，预览渲染在 `renders/`；
实测尺寸 35.8 × 40.8 × 84.1 mm）。

## 需要放什么

| 文件 | 必需？ | 说明 |
| --- | --- | --- |
| 支架 STL/STEP | ✅ | 已放入（上面的 .step）；文件名统一用英文小写+下划线 |
| 相机本体 STL/STEP | 可选 | 没有就先用长方体占位（渲染中看不到相机自己） |
| `notes.txt` | 建议 | 相机型号、大致尺寸（长宽高 mm）、FOV/视场角（规格书有就写上） |
| `photo_front.jpg` / `photo_side.jpg` | ✅ | 两张照片：正视图 + 侧视图，**画面里带上机械臂或桌面做参照**，用于确定相机装在哪儿、镜头朝哪、离手臂多远 |

## 我会做什么

1. 把网格转进 MJCF 场景，按照片确定安装位姿；
2. 在场景里加 `<camera>`（位置/朝向/FOV）；
3. 做"标定渲染"：真机拍一张 vs 仿真同机位渲染一张并排对比，迭代到视角一致；
4. 接通仿真机器人的 `observation.images.*`，仿真录制即带画面。
