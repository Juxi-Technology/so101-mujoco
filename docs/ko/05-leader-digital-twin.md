# 05 · 리더 암 디지털 트윈(실물 암으로 시뮬레이션 암 구동)

손으로 **실물 리더 암**을 움직이면 **MuJoCo 창 안의 시뮬레이션 팔로워 암**이 실시간으로 그대로 따라갑니다. 디지털 트윈 데모와
시뮬레이션 데이터 수집의 올바른 실행 방법입니다.

## 사전 준비

리더 암이 캘리브레이션되어 있어야 합니다([03](03-hardware-calibration.md) 참조). 시리얼 포트는 `COM163`을 예로 듭니다.

## 명령

```bash
export UV_CACHE_DIR='C:\Users\admin\AppData\Local\Temp\uv-cache'
uv run --frozen --with mujoco python examples/so101_mujoco/teleoperate.py \
    --robot.type=so101_mujoco \
    --teleop.type=so101_leader_trim --teleop.port=COM163 --teleop.id=juxi_leader \
    --teleop.use_degrees=false
```

- `--robot.type=so101_mujoco`: 제어 대상이 시뮬레이션 암이며 창이 자동으로 열립니다.
- `--teleop.*`: 조작 장치는 실물 리더 암입니다(순수 읽기 전용, 토크를 절대 걸지 않아 리더 암에 위험 없음).
- `--teleop.use_degrees=false`: **필수**. 리더 암의 출력 단위(스트로크 비율 방식)를 시뮬레이션 암과 일치시킵니다.

`--robot.type`을 `so101_follower --robot.port=COM172 --robot.id=juxi_so101 --robot.max_relative_target=5`로 바꾸면
"실물 리더 암 → 실기 팔로워 암"의 일반적인 키트 활용법이 되며, 동일한 리더 암 캘리브레이션이 그대로 통용됩니다.

## 영점이 치우쳐 있으면: 자동 중심 미세 조정(`so101_leader_trim`)

**증상**: 리더 암을 "눈대중 중간 위치"에 놓아도 시뮬레이션 암이 몇 도 어긋납니다.

**원리**: lerobot의 정규화 영점 = **캘리브레이션 시 스윕으로 기록된 범위의 중간점** `(min+max)/2`입니다. 반면 캘리브레이션에서 Enter를 누를 때의
"중간 자세"는 원시 값 2048로 기록됩니다. 특정 관절의 기계적 스트로크 자체가 비대칭이면 두 "중간점"은 항상 고정된 양만큼 차이가 납니다
(실측 1번 서보: 기록 범위 776~3457, 중간점 2116, 2048과의 차이 68 카운트 ≈ **5.6°**).
**이 편차는 재캘리브레이션으로 없앨 수 없으며**(스트로크 비대칭은 기계 구조가 결정), 소프트웨어에서 보정해야 합니다.

**해결**: `so101_leader_trim` 플러그인이 캘리브레이션 파일에서 공식에 따라 각 관절의 보정값을 자동 계산해 실시간으로 빼 주므로,
재캘리브레이션 후에도 자동으로 따라가며 수동 튜닝이 필요 없습니다:

```
补偿ᵢ = (2048 − minᵢ) / (maxᵢ − minᵢ) × 200 − 100
```

이 머신에서 실측된 적용값(시작 로그에 출력됨):

| 관절 | 보정(단위) |
| --- | --- |
| shoulder_pan | −5.11 |
| shoulder_lift | −0.92 |
| elbow_flex | +2.54 |
| wrist_flex | +0.69 |

나머지 관절의 편차는 <0.05로 보정이 필요 없습니다. 그리퍼(0~100)와 각도 방식 모드는 미세 조정에 참여하지 않습니다.

> 개발자 노트: 이 플러그인의 `name`은 반드시 `"so_leader"`로 유지해야 합니다. `name`은 캘리브레이션 파일을 찾는 디렉터리 키이므로,
> 사용자 정의 타입 이름을 쓰면 캘리브레이션 파일을 찾지 못해 재캘리브레이션 절차가 잘못 실행됩니다.
