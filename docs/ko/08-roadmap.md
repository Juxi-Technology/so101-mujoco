## 다음 단계(가치 순 정렬)

### 2단계 · 카메라의 장면 통합(진행 중)

**완료된 것**:
- 브래킷(STEP→STL)과 카메라(HBVCAM-F2170HD V22 데이터시트 25×30×5.2mm에 따라 만든 플레이스홀더)를 시뮬레이션에 조립하고,
  자세는 `adjust_mount.py` / `adjust_camera.py`로 실기와 대조해 조정했습니다.
- `<camera>` 요소 연결(`sim_cam`, fovy 초기값 49°), **시뮬레이션 비전 녹화 파이프라인 개통**:
  `--robot.image_camera=sim_cam`만 지정하면 `observation.images.wrist` 비디오 데이터셋이 생성됩니다(스모크 테스트 [5] 전부 통과).

**2026-10-16 업데이트**: 카메라 조준/fovy가 만족스러운 수준으로 조정되었습니다(`adjust_camera.py`에 **live view 실시간 화면 창** 추가,
중단점부터 이어서 조정, 창을 실수로 닫으면 자동 재오픈; 또한 MuJoCo 카메라 뷰 방향=**요소 −Z**로 인한 "렌즈 방향과 화면이 반대" 버그 수정,
자세한 내용은 [07](07-troubleshooting.md) 참조). 새로 캘리브레이션한 리더 암으로 비전 데이터셋을 정식 녹화 완료(wrist 영상 포함, 추종 오차 ≤2 단위) ✅;
이전 실험 녹화는 2026-10-16에 정리했으며, 정식 데이터셋은 `so101_sim_vision`(듀얼 카메라)으로 통일되었습니다.
**같은 날 시뮬레이션 로봇이 mujoco_menagerie의 SO-ARM100 모델로 이전**(2026-10-16): 원래 튜토리얼 모델은 그리퍼가 집을 수 없었으나,
새 모델은 그리퍼가 실기 CAD 충돌 형상이고 실측에서 34mm 블록을 안정적으로 집을 수 있습니다. 녹화/텔레오퍼레이션/듀얼 카메라/작업 영역 파이프라인은 모두 유지되며,
실기 텔레오퍼레이션으로 한 차례 재확인 대기 중입니다(특히 wrist_roll 방향 부호).
**남은 작업**: 실기 HBVCAM을 연결한 뒤 "실기 촬영 vs 시뮬레이션 렌더링" 대조 미세 조정;
선택 사항: 카메라 본체 STL로 플레이스홀더 교체. 실기 측 카메라 구성(`--robot.cameras` OpenCV)도 추후 동일하게 진행합니다.

### 3단계 · 장면과 규모화(진행 중)

- ✅ 작업 영역 장면 통합(2026-10-16): 받침판 + 삼색 블록(34mm, 파지 가능) + 수납함 + 고정 탑뷰 카메라 `top_cam`
  (`so101_assets.add_workspace`에 정의, 렌더링/효과 확인 도구 `preview_workspace.py`); **듀얼 카메라(wrist+top)
  녹화 파이프라인 개통**(`--robot.top_camera=top_cam`);
- **자동 데이터 생성**: 스크립트 정책/RL을 시뮬레이션에서 밤새 배치로 실행(인간 개입 없음)하는 것이 "수십 배 효율"의 원천입니다.
- 비전 도메인 랜덤화(텍스처/조명/카메라 지터)로 sim2real을 준비합니다.

### 4단계 · 학습과 배포

- ✅ **학습/배포 파이프라인 실측 완료**(2026-10-16): `lerobot-train`(ACT, CPU 12스텝 스모크 — 약 2s/스텝, loss 정상 감소,
  checkpoint 예상대로 저장)과 `lerobot-rollout --strategy.type=base`(시뮬레이션에서 실제로 정책을 20s 실행,
  종료 시 암을 자동으로 초기 자세로 복귀 후 마무리) 모두 개통. 전체 명령, 요점, 이어서 학습하는 방법은 [09](09-usage-tutorial.md) 7/8절 참조,
  튜토리얼에 포함된 데모 checkpoint `outputs/train/smoke_act`로 배포 파이프라인을 바로 시험할 수 있습니다.
- 정식 학습은 **GPU가 있는 머신**에서 진행합니다(ACT / SmolVLA; 이 머신의 순수 CPU는 소량 스텝으로 파이프라인 검증에만 적합).
  데이터셋을 복사하거나 HF 비공개 저장소에 푸시하면 됩니다.
- 실기 배포도 동일하게 `lerobot-rollout`을 사용합니다(`--robot.*`를 `so101_follower` 구성으로 교체).

### 장기 · sim2real

시뮬레이션 데이터 + 소량의 실기 데이터를 혼합 학습 → 실기에서 비용 없이 평가(시뮬레이션에서 정책 성공률을 재현 가능하게 평가).
주의: 순수 시뮬레이션 데이터를 그대로 실기에 적용하는 것(제로샷 전이)은 가장 어려운 경로이므로, 먼저 "짧은 루프"(실기 데이터 학습 → 실기 배포)를 하고,
시뮬레이션을 점진적으로 더해 가는 것이 좋습니다.

## 한 줄 포지셔닝

실물 암을 이미 보유한 팀에게: 시뮬레이션 = **개발 샌드박스 + 데모 자료 + 데이터 증폭기**;
잠재 고객에게: 시뮬레이션 = **구매 전에 전체 워크플로를 경험할 수 있는 체험 도구**.
