## 必ず覚えておくべき 3 つの約束

1. **単位系（三者一致）**：5 つのボディ関節は **−100〜100**（ストローク比率、0 = ストローク中点）、グリッパは **0〜100**
   （0 = 閉じ）。実機（`use_degrees=false`）、シミュレーション、リーダーアームはすべてこの約束に揃えており、録画したデータセットは公式の
   `lerobot/svla_so101_pickplace` などの実機データセットと同じ構造（6 次元ベクトル + 関節名）になります。
2. **役割の対応**：制御対象（実機またはシミュレーション）には常に `--robot.*`、操作デバイス（キーボード／リーダーアーム）には常に `--teleop.*` を設定します。
3. **本機のコマンドプレフィックス**：この開発機ではすべての `uv` コマンドで先にキャッシュディレクトリを設定する必要があります（理由は [07](07-troubleshooting.md)）：

   ```bash
   export UV_CACHE_DIR='C:\Users\admin\AppData\Local\Temp\uv-cache'
   ```
