# 02 · シミュレーションモデル検証（MJCF の読み込みと駆動）

## モデルの出所

SO-ARM101 の公開 MJCF モデル 3 種は、本プロジェクトですべて動作確認済みです：

| 略称 | ファイル | 出所 |
| --- | --- | --- |
| 公式-新キャリブ | `SO101/so101_new_calib.xml` | TheRobotStudio/SO-ARM100 公式リポジトリ；**本リポジトリのチュートリアル zip 内に同一の副本あり**（バイト単位で一致） |
| 公式-旧キャリブ | `SO101/so101_old_calib.xml` | 同リポジトリ（zip には含まれず、ダウンロードが必要） |
| ROS2 記述パッケージ | `so_arm101_description/mjcf/so_arm101.xml` | 本リポジトリのチュートリアル添付 `SO-ARM101_ROS2.zip` |

注：zip 展開フローは初期版の `so101_assets.py` が提供したもので、参照可能な形で残しています。2026-10-16 以降、シミュレーションロボットは
**mujoco_menagerie の SO-ARM100 モデル**に移行済みです（`assets/menagerie_so_arm100/` に vendored、移行理由と要点は [07](07-troubleshooting.md) の設計説明を参照）。

## 駆動とレンダリングの検証

```bash
export UV_CACHE_DIR='C:\Users\admin\AppData\Local\Temp\uv-cache'
uv run --frozen --with mujoco python examples/so101_mujoco/load_and_drive.py \
    --model "<模型路径>" --out-dir out
```

スクリプトは構造サマリ（関節／アクチュエータ／ゲイン／範囲）を出力し、「6 関節を 1 つずつスイープ + 協調サイン」の検証動画と静止画をレンダリングします。
構造サマリのサンプルは `reports/` にあります（リポジトリに同梱）；比較用動画（`media/`）はサイズが大きいためリポジトリには含まれません——上記のコマンドでいつでも再生成できます。

## 3 モデルの主な差異（実測）

| 項目 | 公式-新キャリブ | 公式-旧キャリブ | ROS2 記述パッケージ |
| --- | --- | --- | --- |
| ゼロ位置の意味 | 関節**ストローク中点** | 水平**完全伸展**位置 | ストローク中点 |
| 関節名 | `shoulder_pan` | 左に同じ | `shoulder_pan_joint`（サフィックス付き） |
| 位置ゲイン | kp=998.22, kv=2.731 | **kp=17.8, kv=0** | kp=998.22 |
| グリッパ単位 | ラジアン hinge | ラジアン hinge | **0〜1 正規化** |
| 自己衝突除外 | なし | なし | あり（6 ペア） |

**追従誤差の実測**：新キャリブと記述パッケージは静止保持誤差 0.0005 rad、旧キャリブは 0.03 rad（下垂約 1.7°、kp が 56 倍弱い）。
シミュレーションで同一ポリシーを評価しても、モデルを変えると動特性が変わります。どれで記録したかに注意してください。

## 必ず覚えておくべきモデル挙動

1. **`shoulder_lift` の正方向は下向き**：駆動トルクでは「下げ振り」に正の角度を使います。遠隔操作のマッピングやデータ換算の前に符号を確認してください。
2. **地面に当たれば止まる**：下げ振りの限界で指先が地面に接触して止まります（スクリプトには 8cm の対地保護による自動振幅クリップを組み込み済み）。
3. 公式モデルにはカメラも keyframe もありません。カメラ付きの変種 `so101_new_calib_camera.xml` が存在し、将来の視覚データ録画に使えます。
