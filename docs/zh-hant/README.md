## 三條必須記住的約定

1. **單位制（三方對齊）**：五個身體關節使用 **−100~100**（行程比例，0 = 行程中點），夾爪使用 **0~100**
   （0 = 閉合）。實機（`use_degrees=false`）、模擬、主動臂全部對齊此約定；錄出的資料集與官方
   `lerobot/svla_so101_pickplace` 等實機資料集結構一致（6 維向量 + 關節名稱）。
2. **角色對應**：受控對象（實機或模擬）永遠搭配 `--robot.*`；操控裝置（鍵盤/主動臂）永遠搭配 `--teleop.*`。
3. **本機指令前綴**：這台開發機上所有 `uv` 指令都需要先設定快取目錄（原因見 [07](07-troubleshooting.md)）：

   ```bash
   export UV_CACHE_DIR='C:\Users\admin\AppData\Local\Temp\uv-cache'
   ```
